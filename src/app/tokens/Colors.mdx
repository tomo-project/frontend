# Colors

화면에는 Semantic 색만 씁니다. Primitive는 Semantic의 별칭 대상이며 직접 쓰지 않습니다.

Tailwind 클래스에서는 `--color-` 접두사를 뺀 이름으로 사용합니다.  
(예: `bg-bg-soft`, `text-text-muted`, `bg-accent-tomato`, `border-border-focus`)

<br />

## shadcn 매핑

Figma 변수의 코드 문법(code syntax)과 같은 대응입니다.

<ColorPalette>
  <ColorItem
    title="Primary / Secondary"
    subtitle="bg-primary, bg-secondary"
    colors={{
      primary: 'var(--primary)',
      'primary-fg': 'var(--primary-foreground)',
      secondary: 'var(--secondary)',
      'secondary-fg': 'var(--secondary-foreground)',
    }}
  />
  <ColorItem
    title="Muted / Accent / Destructive"
    subtitle="bg-muted, bg-accent, text-destructive"
    colors={{
      muted: 'var(--muted)',
      'muted-fg': 'var(--muted-foreground)',
      accent: 'var(--accent)',
      destructive: 'var(--destructive)',
    }}
  />
  <ColorItem
    title="Border / Input / Ring"
    subtitle="border-border, border-input, ring-ring"
    colors={{ border: 'var(--border)', input: 'var(--input)', ring: 'var(--ring)' }}
  />
</ColorPalette>
