# TOMO 디자인 시스템

[Figma Foundations v2](https://www.figma.com/design/wJD1zrOCuk5Vd06ZZHvzAc/TOMO-design?node-id=326-71)의 변수와 컴포넌트를 코드로 옮긴 것입니다. 토큰은 `src/app/globals.css`, 공용 UI는 `src/shared/ui`에 있고, 화면에서는 `@/shared/ui`에서 가져다 씁니다.

```tsx
import { Button, Card, CardHeader, toast } from '@/shared/ui';
```

## 토큰 쓰는 법

- Figma 변수 이름의 `/`를 `-`로 바꾸면 클래스 이름이 됩니다. `bg/soft` → `bg-bg-soft`, `text/muted` → `text-text-muted`, `accent/tomato` → `bg-accent-tomato`.
- 간격은 px 숫자 그대로 씁니다. `p-16`은 16px, `gap-8`은 8px입니다. Tailwind 기본 배수(4px 단위)가 아닙니다.
- 글자는 텍스트 스타일 하나로 크기·줄 간격·굵기를 함께 정합니다. `text-label`, `text-heading-3`처럼 쓰고 `font-bold`를 따로 붙이지 않습니다.
- 색·간격·그림자 값을 `[#d94b45]`, `[13px]`처럼 직접 쓰지 않습니다. 맞는 토큰이 없으면 먼저 Figma에 추가할지 논의합니다.

자세한 값은 **Tokens** 문서(Colors, Typography, Spacing & Radius, Elevation)에 있습니다.

## 그림자: 플랫과 뉴모피즘

- 흰 페이지(`bg-bg-page`, `bg-bg-card`) 위의 카드·팝오버·다이얼로그는 **플랫** 그림자(`shadow-card`, `shadow-popover`, `shadow-dialog`)를 씁니다.
- `variant="soft"` 버튼과 `shadow-raised-*`, `shadow-inset`은 **`bg-bg-soft` 쟁반 위에서만** 씁니다. 흰 바탕에서는 밝은 그림자가 묻혀 눌린 듯한 효과가 사라집니다.

## 접근성 약속

- 모든 조작 요소는 키보드로 닿고 `focus-visible`일 때 토마토색 외곽선이 보입니다.
- 아이콘은 `aria-label`이 없으면 장식으로 보고 숨깁니다. 아이콘만으로 뜻을 전할 때는 `aria-label`을 넣습니다.
- `Input`·`Select`는 `label`·`helper`를 넘기면 연결(`htmlFor`, `aria-describedby`)이 자동으로 걸리고, `status="error"`면 `aria-invalid`가 붙습니다.
- 각 컴포넌트 스토리의 play 테스트가 키보드 동작과 읽기 이름을 확인합니다.
