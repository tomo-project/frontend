# Typography

폰트: **Pretendard** (`font-sans`, `font-heading`)

행간은 글자 크기에 대한 비율입니다. `text-timer-xl`은 타이머 숫자에만 씁니다.

아래 예시는 실제 Tailwind 클래스로 렌더링됩니다.

<br />

export const scale = [
  {
    cls: 'text-timer-xl',
    figma: 'Numeric/Timer XL',
    size: '96 / 1.1 / -1',
    weight: 'Bold',
    sample: '18:42',
  },
  { cls: 'text-display', figma: 'Display', size: '48 / 1.2 / -0.5', weight: 'Bold' },
  { cls: 'text-heading-1', figma: 'Heading/H1', size: '36 / 1.3 / -0.5', weight: 'Bold' },
  { cls: 'text-heading-2', figma: 'Heading/H2', size: '24 / 1.4', weight: 'Bold' },
  { cls: 'text-heading-3', figma: 'Heading/H3', size: '20 / 1.4', weight: 'Bold' },
  { cls: 'text-body', figma: 'Body/Regular', size: '16 / 1.6', weight: 'Regular' },
  { cls: 'text-body-bold', figma: 'Body/Bold', size: '16 / 1.6', weight: 'Bold' },
  { cls: 'text-label', figma: 'Label/Regular', size: '14 / 1.5', weight: 'Regular' },
  { cls: 'text-label-bold', figma: 'Label/Bold', size: '14 / 1.5', weight: 'Bold' },
  { cls: 'text-caption', figma: 'Caption/Regular', size: '12 / 1.5', weight: 'Regular' },
  { cls: 'text-caption-bold', figma: 'Caption/Bold', size: '12 / 1.5', weight: 'Bold' },
  { cls: 'text-logo', figma: 'Brand/Logo', size: '20 / 1.2 / 2', weight: 'Bold', sample: 'TOMO' },
];

<Unstyled>
  <div className="flex flex-col gap-24 font-sans text-text-primary">
    {scale.map(({ cls, figma, size, weight, sample }) => (
      <div key={cls} className="flex items-baseline gap-24 border-b border-border-subtle pb-16">
        <div className="w-[200px] shrink-0">
          <code className="text-label">{cls}</code>
          <div className="text-caption text-text-secondary">{figma}</div>
          <div className="text-caption text-text-muted">
            {size} · {weight}
          </div>
        </div>
        <span className={cls}>{sample ?? '오늘의 작은 집중, TOMO와 함께해요. 123'}</span>
      </div>
    ))}
  </div>
</Unstyled>

<br />

크기 / 행간 / 자간(px) 순서입니다. 자간이 없으면 0입니다.
