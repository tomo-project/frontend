# 구현·테스트 확인 목록

코드를 쓰기 전에 읽고, 끝내기 전에 해당하는 줄을 다시 본다.
`AGENTS.md`에 있는 규칙은 여기에 다시 쓰지 않는다.

## 구현

- 쓰기 전에 찾는다. 있는 공용 부품·토큰·함수를 먼저 쓰고, 새 파일과 헬퍼는 마지막에 만든다.
- 오류를 삼키지 않는다. 빈 `catch`, 조용한 기본값(`?? 0`), 실패를 성공처럼 보이는 화면을 만들지 않는다.
- 일어날 수 없는 경우의 방어 코드, 안 쓰는 props, 미래 대비 옵션, 한 번 쓰는 추상화를 만들지 않는다.
- 주석은 '왜'만 쓴다. 날짜, `Step 1:`, 구분선 주석, `console.log`, 막연한 TODO를 남기지 않는다.
- 예외를 덧붙이지 않는다. 가이드와 다르면 코드를 공용 값에 맞추고, 규칙을 바꿀 일이면 정본 한 곳을 고친다.

## 테스트·확인

- 기대값이 틀려 보이면 고치지 않고 멈춰서 보고한다. 스냅샷도 같다.
- 테스트 skip과 검사 끄기(`eslint-disable`, `@ts-ignore`, `--no-verify`)를 쓰지 않는다.
- 바꾼 화면은 시안과 같은 폭으로 대조하고, 바꾼 동작은 실제로 눌러 본다.
